# 任务一、任务二实现与验收状态

## 实现

任务一保留基础层与附件明细，按最新答疑区分实际成交、需求预算、入围意向。标准输出为总表、标的表、投标人表，金额换算万元，未知不置为0，不用包总价减法或不明确数量乘法补值。独立价格投影只接受唯一明示标的行、该价格列明确单位及原数字精确等价。

任务二在现有MySQL新增版本化`t2_`数据层，不另起图库服务。国产模型的已有缓存是候选，HTML证明与保守后处理负责验证；不是重新收费抽取。五查询为合作供应商/产品供应商、高频竞标及组合、共同竞标主体、共同采购人、共同竞标项目与结果。图、表、原文证据固定同一dataset_id。

`announcement_count`是按原文公告去重的记录数，不是已确认法人和采购轮次后的交易数。未知身份时`transaction_count`、无法去重或归属的金额为NULL；不能把这些空值作为0或无业务。品牌不是制造商，联合体是一个竞标主体，成员不能重复分配全包金额。完整名单须有独立原文证据，TOPN和已知共现组合不宣称完整名单或围标。未知竞标结果不推断为未中标。

## 启动与测试

后端依旧在`task1_entity_extraction`下运行`python -m uvicorn api.main:app`，前端`npm run build`。新增包为项目根的`task2_relationship_analysis`和`task2_query_service`，发布时可放在backend内。默认公开测试：`python -B -m pytest`；Task1回归另运行`python -B -m pytest task1_entity_extraction/tests`。私有原文测试显式标记，不随数据公开发布。

离线事实构建：`python -B -m task2_relationship_analysis.cli build --html-root <原HTML目录> --legacy-raw <旧关系候选JSON> --v11-raw <只读产品候选JSON> --output-root <新目录> --expected-count 1038`。输出不可变版本，不修改输入，不调用模型。`verify`需要私有输入路径receipt，只用于拥有数据的本地环境；不提交receipt或输出到公共仓库。

需要显式运行私有来源回归时，配置`TASK2_PRIVATE_HTML_ROOT`、`TASK2_PRIVATE_LEGACY_RAW`、`TASK2_PRIVATE_V11_RAW`并使用`-m private_data`；未配置时不伪造数据或读取开发者硬编码路径。

标准三表工具在`tools/task1_standard_export`。生产接口下载经过保存文件校验的`release_assets/task1-standard.xlsx`，不在HTTP请求中重新抽取。旧实验回放工具仍需私有冻结基线及校验记录；可用`TASK1_PRIVATE_WORKSPACE`、`TASK1_STANDARD_BACKEND`、`TASK1_STANDARD_HTML_ROOT`和`TASK1_STANDARD_R9_DIR`配置，不提供或伪造私有数据。

## 部署与安全边界

Ubuntu24.04、2vCPU/4GB、一个API worker、MySQL、Nginx；不常驻GPU模型。事实内存缓存仅保留一个版本。SQL导入事务发布，重复导入必须核对存储内容的完整canonical哈希和覆盖文件哈希；不覆盖旧版本。运行时上传目录应为独立shared目录，不能让服务账号改写代码或冻结资源。

网页上传默认仅解析。`PAID_INFERENCE_ENABLED=1`与服务器`MODEL_RUN_TOKEN`及请求Bearer令牌均满足才可显式请求收费推理，配置API key本身不构成费用授权。正式发布默认关掉收费推理。令牌与key只保存在受限服务器配置，不写入代码或公开材料。

发布先克隆旧库到隔离库；保留既有项目/投标人行。须真实验证1038公告、6784原始基础行、14110按既有规则保存的附件明细，重复导入、失败回滚、五类正向HTTP、证据/原文附件、实际服务账号上传与2核4GB延迟/内存。标准三表行数1470/6776/6172不同于原始层，是分类和汇总口径差异。未逐项证明的附件明细不作为实际交易或准确率。

线上切换还必须绑定发布清单和目标库指纹、精确文件目录、交互页面验收及旧库指纹；异常须恢复原env/current并检查旧服务健康。未完成这些门槛不得称上线完成。比赛数据、原文、仲裁金标、账号信息、数据库备份、输出和训练材料不公开提交Git。

守卫式部署代码在`deploy/task1-task2`：隔离验收需要管理员预先创建目标库，脚本拒绝写线上库或覆盖非空库；管理员切换需要独立验收报告及页面交互门槛。该目录只提交代码和合成守卫测试，不提交私有发布包或验收数据库。没有云端运行报告时不可视作部署完成。
