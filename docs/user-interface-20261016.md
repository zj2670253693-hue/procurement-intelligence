# 用户界面与用词整理（2026-10-16）

## 目标和范围

普通用户优先看到采购信息、信息来源和下一步操作；哈希、版本、内部编号和调试信息保留，但默认折叠。本轮仅调整前端，不修改七字段、查询条件参数、事实关系、价格、身份合并、模型授权或数据库。

## 改动

- 来源抽屉改为“信息来源”。下拉项使用“来源 1 · 公告章节”等可读名称，不显示 evidence 哈希作为选项名称。默认展示来源文件类型、公告章节、业务公告编号与原文内容。
- 完整证据编号、数据版本、SHA256、原文定位及表头保留在默认折叠的“技术详情”中。仍使用原始完整 ID 调用接口，同一版本追溯不变；只修改展示标签。
- 查询耗时和数据版本收进“统计口径与技术信息”。导航及页面改用“公告与采购信息”“供应商与采购关系”“上传与处理”等业务名称，不再把任务号作为主要菜单标题。
- 个人上传使用“我的上传 N · 智能提取/仅读取文件 · 状态”的显示名称，上传历史不直接铺开内部任务号。编号 N 只表示当前列表中的显示顺序，不是数据库身份或永久编号；路由、筛选、所有权校验仍使用完整原 ID，不按显示名称合并记录。
- 上传任务、模型预留额度和 JSON 诊断默认折叠；失败、不完整、可能计费、额度耗尽及实际用量未确认提示保持直接可见。未改变预算设置、重试、取消及上传协议。
- 筛选占位提示使用中文字段名，原文及附件待核实提示简化。统计页明确填充率不等于准确率，不再把填充程度标成提取效果“优秀/良好”。
- 来源文本仍以 Vue 文本插值显示，不执行 HTML；加载失败显示重试入口。没有新增源公告全文下载或跳转功能，也没有猜测公告标题。

## 发布前验证

- 30 项前端测试通过，生产构建通过；原有大分包和动态/静态导入警告保留，不在本轮扩展重构。
- 实际 SFC 模板编译/SSR 检查：技术信息默认折叠、完整 ID 保留、可读来源名称、危险原文转义、错误提示与重试入口。
- 使用最终生产构建配合真实 HTTPS API，五类正例结果仍为 2、4、3、1、1；原文摘录未改，版本仍可在技术详情核对，默认页面及选项不显示技术 ID。
- 桌面和 430 像素窄屏来源抽屉通过检查；窄屏内容没有横向溢出。既有私人部分成功批次的警告及可能计费说明仍可见。

本节记录的是本地候选前端与真实 API 的验证，不是已上线证明，不代表官方基准评测。发布后仍须独立公网复验。本轮未发起新的抽取任务或大模型调用。
